# 飆風玫瑰 × 生於憂患｜逆境九宮格

體育班高中國文課用的 3×3 賓果遊戲。外圍 7 格是選擇題，第 9 格是「我的偶像名言」上傳任務，中央格寫一句觀影心得、拍照並貼到 Padlet；只要有一條通過中央的線就能交出成果、領「MVP 逆境覺醒通關勳章」。

## 一、開啟 GitHub Pages

Settings → Pages → Source 選 **Deploy from a branch** → Branch 選 **main / (root)** → Save。約 1 分鐘後網址就能開。

## 二、部署 Apps Script（收成績）

1. 新建一個 Google 試算表 → **擴充功能 → Apps Script**。
2. 把 `apps-script/Code.gs` 全部貼上（取代原本內容）。
3. 改**第 8 行**密碼：`const PASSWORD = '……';`（10 字以上、英數混合）。
4. 把老師另外收到的「答案區」貼進 `ANSWERS` 區塊（GitHub 上這裡是空的，故意的）。
5. **部署 → 新增部署作業 → 網頁應用程式**：執行身分「我」、存取權「所有人」→ 授權。
6. 複製 `/exec` 結尾的網址，填進 `config.js` 的 `sheetApi`。
7. 直接打開 `/exec` 網址看到 `{"ok":true,...,"answersReady":true}` 就是正常的。

> 之後若 Code.gs 有更新：重新貼上 → 再改一次密碼、再貼一次答案 → **部署 → 管理部署作業 → 編輯 → 版本選「新版本」**。網址不變。

## 三、老師檢視

- `#scores` 輸入密碼登入：排行榜、作答紀錄（可篩座號、只看疑似亂答、複製到 Excel）、各題分析、誓言牆、學生診斷（可列印報告書）。
- 教師區：公布解答、開放重玩（單人或全部）、班級名單、匯出 CSV、清除班級、匯入成績碼、刪除單筆作答。
- 試算表會自動出現兩個工作表：`data`（程式用）與 `作答紀錄`（老師看，可直接篩選）。

## 注意事項

- 答案、解析與密碼只在老師的 Apps Script 裡；GitHub 上沒有。計分由後端算。
- 學生答錯才會看到提示；報告書預設不顯示逐題答案，老師按「公布解答」後才出現。
- 同一個班級座號交過後不能再交，除非老師開放重玩。座號限 1～60。
- 密碼連錯 5 次會暫停登入 10 分鐘。用公用電腦看完記得登出。
- `config.js` 的 `sheetApi` 留空時是本機模式，只能試玩介面，不計分。
